# Contributions And Boundaries

## Human Contribution

TothMark originated the RED/BLUE project concept and its goals: reduce hallucination, unchecked reasoning, and answer drift; make the steps visible; and compare against Single AI without forced positive scores. TothMark directed the exploration, questioned poor outputs, and requested honest tests, timing, token accounting, and logs.

The pre-action safety-review direction and prompt-driven image-workflow direction also came from TothMark. They remain early concepts.

## AI Assistance

The assistant helped implement the local web prototype, develop prompts and evaluation machinery, run tests, investigate failures, and write this portfolio. The author does not claim that all code or experimental design was produced independently by them.

- No claim that the safety concept eliminates dangerous actions or that a prompt is a security boundary.
